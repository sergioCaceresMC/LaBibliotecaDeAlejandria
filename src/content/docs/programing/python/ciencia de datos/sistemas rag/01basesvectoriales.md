Las bases vectoriales son una forma de representar archivos, o cosas con un vector multidimensional mediante una cosa llamada embeding. Con un poco de suerte podré convencer a alguien más para que explique esta parte.

## Pequeño laboratorio usando CHROMADB

Esta es una base vectorial que puedes tener en local usando un entorno virtual. Sirve para entender conceptos.
