Los sistemas RAG son los sistemas de Generación Aumentada por Recuperación por sus siglas en ingles.

No voy a mentir, no me gustan los sistemas RAG con LLM para recuperar información por cuestiones éticas. Pero el método y funcionamiento tienen diferentes usos, como la recuperación de archivos de una base vectorial.

Para que aprendas las bases de los sistemas RAG te sugiero este [artículo](https://www.tecnoloblog.com/sistemas-rag/) y este video:
