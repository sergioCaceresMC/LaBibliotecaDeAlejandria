Esta parte es más experiencia propia. Aquí hay una lista de los programas que uso (gratuitos) con sus pros y sus contras:

## Planificación

- **Excalidraw**: Esta es mi herramienta para hacer planificación rápida. Es una pizarra infinita donde puedes hacer cuadros, escribir, dibujar, conectar cosas, subir imágenes y exportar. Lo malo es que solo tienes una de forma gratuita, pero para mi es incluso mejor, así puedo tener todos mis proyectos en el mismo sitio. [excalidraw.com](https://excalidraw.com/)

- **DrawIO**: Es de google, lo tienes en Drive. Sirve para diseños más específicos, y profesionales. Por ejemplo, diagramas UML; el programa ya trae plantillas para estos diagramas y no tengo que usar herramientas externas. El problema a mi parecer y por el que uso más Excalidraw, es porque es muy complejo y ortopédico; si quiero crear una caja y hacerlo de manera rápida, prefiero no tener 50 herramientas a la mano. Este programa es más orientado a cosas para presentaciones. [drawio.com](https://www.drawio.com/)

- **Miro**: Esto es un poco como DrawIO, pero no es completamente gratis. Tiene una capa gratuita muy generosa, pero dependiendo del proyecto se te puede quedar corto. Lo bueno es que es mucho más sencillo de usar y tiene a mi criterio las mismas capacidades. Lo malo, lo que he comentado; no es completamente gratuito. [miro.com](https://miro.com/)

## Diseño de arquitecturas

- **DBDesign**: Esta app está bien para diseñar bases de datos relacionales y plantearlas de forma visual. Es lo que yo uso luego de hacer el diseño de entidad relación. [dbdesign.io](https://playground.dbdesign.io/)

- **Ver JSON esquema**: Esta herramienta es más para comprobar el diseño del esquema realizado para aplicaciones que requieren usar JSON. Yo lo he usado principalmente para comprobar la estructura json en bases de datos NoSQL como MongoDB. [chartflow.net](https://chartflow.net/es/ai/json-schema-visualizer)
