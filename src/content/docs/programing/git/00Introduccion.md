Un conocimiento impresindible y cada vez menos estudiado con los avances de la IA es el manejo de Git. Esta es una herramienta para el control de versiones que permite programar en equipo.
Git es necesario en todas las empresas de software y aunque luego la plataforma de almacenamiento puede cambiar, el estandar sigue siendo GitHub. Así que recomiendo mucho este curso.
