## ¿Qué es nginx?

Una breve descripción si no quieres ver el video: Nginx es un servidor web de código abierto diseñado para ofrecer alto rendimiento, estabilidad y bajo consumo de recursos. Funciona como servidor HTTP, proxy inverso, balanceador de carga y caché de contenido. Su arquitectura basada en eventos le permite manejar miles de conexiones simultáneas de manera eficiente, convirtiéndolo en la elección preferida para sitios con alto tráfico.
